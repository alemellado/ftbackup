FTBACKUP

Backup automático para os sistemas de gestão desenvolvidos por Alexandre Mellado

O que é

O FTBACKUP é um programa para Windows que faz cópias de segurança automáticas das pastas de dados dos sistemas de gestão que desenvolvo para meus clientes. Ele compacta os arquivos, confere a cópia e guarda os backups em uma pasta local e, opcionalmente, no Google Drive do desenvolvedor.

Uso do Google Drive

  • O envio ao Google Drive usa somente a permissão drive.file: o programa só enxerga os arquivos que ele mesmo criou. Não tem acesso a nenhum outro arquivo, e-mail ou dado da conta.
  • Cada backup é criptografado (AES-256) antes de sair do computador.
  • O programa apenas envia os backups e apaga os antigos, conforme a quantidade configurada.
