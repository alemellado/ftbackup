Política de Privacidade — FTBACKUP

Vigente desde 9 de novembro de 2026 · Página inicial

O FTBACKUP é um programa de backup para Windows desenvolvido por Alexandre Mellado (alepmsistemas@gmail.com) e instalado nos computadores dos clientes que ele atende. Esta política explica quais dados o programa usa e o que faz com eles.

1. Dados do Google acessados

Quando o envio ao Google Drive é ativado, o programa pede uma única permissão: https://www.googleapis.com/auth/drive.file. Com ela, o FTBACKUP só consegue ver, criar e excluir os arquivos e pastas que ele mesmo criou no Google Drive. Ele não tem acesso a nenhum outro arquivo do Drive, ao e-mail, aos contatos ou a qualquer outro dado da conta Google.

2. Como os dados são usados

  • Enviar os arquivos de backup para uma pasta criada pelo próprio programa.
  • Listar e excluir os backups antigos dessa pasta, conforme a quantidade a guardar configurada.
  • Baixar um backup, quando for necessário restaurar os dados.

Os backups são compactados e criptografados com AES-256 no computador, antes do envio. A chave que abre os backups não fica no computador do cliente nem com o Google.

3. Armazenamento e compartilhamento

O FTBACKUP não tem servidor próprio e não envia dados a terceiros. Os backups ficam somente na conta Google autorizada. A autorização (token de acesso) fica gravada no computador onde o programa está instalado, protegida pela criptografia do Windows (DPAPI). Nenhum dado é vendido, usado para publicidade ou para treinar modelos de inteligência artificial.

4. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

5. Como revogar o acesso

A permissão pode ser retirada a qualquer momento em myaccount.google.com/permissions, removendo o “FTBACKUP”. A partir daí o programa deixa de enviar backups ao Drive. Os arquivos já enviados continuam na conta e podem ser apagados pelo próprio Google Drive.
